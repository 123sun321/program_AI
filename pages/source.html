目录结构

program_AI/
├── index.html          # 本站首页（文档站入口）
├── pages/              # 本站各章节页面
├── assets/             # 样式、脚本与配图
├── backend/            # 后端 Spring Boot 多模块源码（Java / 配置，已脱敏）
├── frontend/
│   ├── managerWeb/     # 教师端与管理端前端源码
│   └── studentWeb/     # 学生端前端源码
├── 访问说明.md          # 在线体验地址与测试账号
└── 原始readme.txt      # 原始提交包说明

说明

  • 为减小体积，原始提交包中的编译产物（jar）、前端依赖（node_modules）与二进制素材未纳入。
  • 配置文件中的数据库地址、账号、密码、密钥等敏感字段已替换为占位符 YOUR_VALUE_HERE，本地运行时请自行填写。
  • 本站为纯静态文档，可直接浏览；真实平台的运行方式见 访问说明。
